# 产品参数核对报告

核对日期：2026-11-08。依据：`public/downloads/datasheets/` 中每个产品的规格书 PDF（Technical Data 表）。

## 总结

- 非铝型材产品共 125 个；其中 109 个有单独规格书，已逐个核对，**全部存在参数错误**，已按规格书改正。
- 16 个产品只链接到整本目录，没有单独规格书，本次未逐个核对（见文末清单）。
- 铝型材 364 个：按 2025 目录抽查（如 TY-2126：10W/m、2700–6500K、24V DC、Ra>90，与目录一致），未发现编造数值；多数字段目录未给出，网站已留空。
- 原数据的共性问题：几乎所有产品都套用了同一组模板值——光效 82/110/170 lm/W、SDCM≤3 (1 Bin)、可任意剪、5m/10m、1800K/5000K 色温、IP68 等，并非来自规格书。
- 规格书没有写的参数一律留空（页面会自动隐藏该行），不再填写推测值。
- 霓虹灯的 LED 类型和每米灯珠数规格书未给出，已全部留空；灯带、灯板的厚度规格书未给出，保留原尺寸图用的厚度值。
- 4 款防眩（UGR<19）霓虹的规格书光通只有 22–33 lm/m（约 2–3 lm/W），明显异常，暂时留空，请工厂确认。
- 产品简介（pitch）和卖点（features）已按规格书重写，删除了“2oz/3oz 铜箔”“1-Bin SDCM≤3”等规格书没有的说法。
